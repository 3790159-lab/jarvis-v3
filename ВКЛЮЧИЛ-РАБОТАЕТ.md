# Jarvis — быстрый старт

## Одна команда (из PowerShell с правами администратора):

```powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
.\scripts\install_service.ps1; .\scripts\nosleep_setup.ps1
```

## Готово. Проверь:

```powershell
Get-Service Jarvis*
```

Все три должны быть `Running`.

## Если что-то не так:

```powershell
.\scripts\restart_services.ps1
```
