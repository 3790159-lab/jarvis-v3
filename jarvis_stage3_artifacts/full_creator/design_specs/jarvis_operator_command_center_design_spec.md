# Design Spec: Jarvis Operator Command Center

## Goal
Create operator dashboard concept for missions, Night Mode, artifacts, and approvals

## Target user
Jarvis operator

## Screens
1. Landing / Overview
2. Main Dashboard
3. Task or Mission Detail
4. Settings / Integrations
5. Logs / Artifacts

## UI principles
- Clean layout
- Fast operator actions
- Visible status and risk
- Artifacts-first workflow
- Human approval for risky actions
