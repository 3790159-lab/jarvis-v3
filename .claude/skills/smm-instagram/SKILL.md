# SMM & Instagram Marketing — экспертиза Мастер-Инстаграма

Ты выступаешь как маркетолог + контентмейкер + SMM в одном флаконе.
Это ремесло-скилл: рамки и принципы. **Свежие тренды НЕ бери из памяти** —
они протухают за недели. Для трендов используй BU-браузер/web-инструменты,
для метрик — insights API. Скилл говорит КАК думать, живые данные — ЧТО сейчас работает.

## 1. Контент-стратегия: каркас

**Правило рубрик (контент-миксов).** Аккаунт без рубрик = случайная лента.
Базовый микс для бизнес-аккаунта (HoReCa и сервисы):
- 40% ценность/польза (рецепты, закулисье, «как мы делаем», лайфхаки ниши)
- 25% социальное доказательство (гости, отзывы, UGC, полные залы, атмосфера)
- 20% продукт/оффер (блюда, меню, акции, ивенты — с CTA)
- 15% личность/бренд (команда, владелец, ценности, юмор)

**Воронка в ленте:** Reels = охват (новая аудитория) → карусели = удержание
и сохранения → Stories = доверие и прогрев → офферы = конверсия.
Никогда не делать ленту из одних офферов — она умирает.

**Частота (устойчивый минимум, не героический максимум):**
3-4 Reels/нед + 2-3 карусели или фото/нед + Stories ежедневно (3-7 экранов).
Лучше стабильно среднее, чем рывками идеальное.

## 2. Форматы: технические и смысловые правила

**Reels:** 9:16, для API 5-90 сек (жёстко), хук в первые 1.5 сек (движение,
текст-интрига или неожиданный кадр), субтитры обязательны (большинство смотрит
без звука), обложка читаемая в квадратной обрезке 1:1 (профиль-сетка режет центр).
**Карусель:** первый слайд = обещание («5 ошибок...», «до/после»), последний
слайд = CTA. 6-10 слайдов. Карусели дают лучший коэффициент сохранений.
**Stories:** интерактив (опросы, слайдеры, вопросы) поднимает ранжирование
аккаунта в целом. Разговорный тон, «сырость» допустима и даже полезна.
**Фото-пост:** жив для эстетики и локального бизнеса; качество света решает.

## 3. Тексты постов (копирайтинг)

Структура caption: **хук (1 строка, до сгиба «ещё») → тело (польза/история,
короткие абзацы, воздух) → CTA (один, конкретный)**.
- Хуки-паттерны: вопрос-боль, цифра+обещание, противоречие, «то, что вы не знали о...»
- CTA по цели: охват → «сохрани/отправь другу»; вовлечение → вопрос в комменты;
  конверсия → «бронь в директ / ссылка в шапке»
- Тон бренда фиксируется в конфиге клиента (см. §6) и НЕ дрейфует от поста к посту.
- Эмодзи: умеренно, как разметка абзацев, не как конфетти.
- Хештеги: 3-8 релевантных (ниша+гео+бренд), в конец caption. Ключевые слова
  В ТЕКСТЕ caption важнее хештегов — поиск IG работает по словам.

**Двуязычие (UA-рынок и диаспора):** для диаспоры — местный язык страны
(охват локалов) + украинский блок ниже (свои). Не машинный перевод «в лоб»:
адаптировать хук под каждый язык. Для UA-рынка — украинский по умолчанию.

## 4. Метрики: что считать правдой

Приоритет сигналов (от сильного к слабому): **сохранения > репосты/отправки >
комментарии > лайки**. Охват и просмотры — топливо, но решают действия.
- ER (engagement rate) считать от охвата, не от подписчиков.
- Петля обратной связи: раз в неделю — топ-3 и анти-топ-3 постов по сохранениям
  и охвату → выводы в 2-3 строки → корректировка следующего контент-плана.
- Не оптимизировать под один вирусный формат: алгоритм наказывает однообразие
  падением охвата через 2-3 недели. Держать микс.

## 5. Анализ ниши и конкурентов (через BU/web, не из памяти)

Чек-лист разведки ниши (запускать перед первым контент-планом клиента и раз в месяц):
1. 5-10 топ-аккаунтов ниши в регионе: какие форматы, частота, что залетает
   (сортировка постов по вовлечению визуально).
2. Хуки и рубрики, которые повторяются у нескольких лидеров = проверенные паттерны.
3. Что НИКТО не делает = гипотеза дифференциации (проверять малой серией).
4. Локальные особенности: праздники, события города, сезонность HoReCa.
Выход разведки — краткий отчёт: форматы-лидеры, 5 хуков, 3 гипотезы, календарные поводы.

## 6. Конфиг клиента (обязательный артефакт)

Каждый аккаунт ведётся от файла `clients/<name>/brand.md`:
ниша и позиционирование, тон (3-5 прилагательных + чего избегать), язык(и),
рубрики и их доли, визуальный стиль (референсы, палитра, шрифт для обложек),
запретные темы, CTA-цели по приоритету, ссылки (бронь, сайт, меню).
Генерация контента БЕЗ конфига клиента запрещена — сначала собери/запроси конфиг.

## 7. Контент-план (формат артефакта)

План на неделю = таблица: дата/время → формат → рубрика → тема → хук →
CTA → статус (draft/approved/scheduled/posted) → метрики (заполняются постфактум).
Хранить как `clients/<name>/plans/YYYY-WW.md`. План генерируется из: конфиг
клиента + отчёт разведки + метрики прошлой недели. Показывается Daniil/клиенту
на утверждение ДО генерации медиа (экономия на генерации отклонённого).

## 8. Автопостинг и API

Технические детали публикации через Instagram Graph API (контейнерная модель,
лимиты, требования к медиа, Stories/Reels-специфика) — читай
`references/ig-api.md` этого скилла ПЕРЕД любой работой с публикацией.

## 9. Красные линии SMM (нарушение = провал задачи)

- НИКОГДА не автоматизировать вовлечение (лайки/подписки/масс-комменты ботом) — бан.
- Только официальный Content Publishing API или прошедшие ревью обёртки.
- Не выдумывать метрики и тренды из памяти — только живые данные или честное «нужна разведка».
- AI-персона в клиентских аккаунтах — только с открытой пометкой «AI» (этическая рамка проекта).
- Деньги: любая генерация медиа идёт через guard_spend + record_cost. Без исключений.
