# MESH_CONTROL_GUIDE.md — Руководство по Mesh Control

## Что такое Mesh Control?

Smart Router анализирует твой запрос и, если задача составная (research + table, analyze + report), 
автоматически разбивает её на шаги и запускает нужных агентов. `/mesh` — это панель управления.

---

## Три режима

| Режим | Когда | Поведение |
|-------|-------|-----------|
| 🎯 **SIMPLE** | Для быстрых ответов | Один агент, без планирования |
| 🤖 **AUTO** (умолчание) | Повседневное использование | Автоматически выбирает: один или несколько агентов |
| 🚀 **ALWAYS** | Максимальный анализ | Всегда активирует mesh, даже для простых запросов |

Переключай прямо в `/mesh` → кнопки [SIMPLE] [AUTO] [ALWAYS].

## Settings — Настройки

Нажми `/mesh` → **🔧 Settings**:

### Подтвердить перед mesh
- **✅ Всегда** — показывать план перед каждым выполнением
- **⚠️ Крупные задачи** (умолчание) — только если > 2 агентов ИЛИ стоимость > $0.05
- **❌ Никогда** — выполнять без подтверждения

### Макс агентов на задачу
- `1` / `3` / `5` (умолчание) / `∞`

### Лимит стоимости задачи
- `$0.05` / `$0.10` (умолчание) / `$0.50` / `∞`

### Cowork делегирование
- **✅ Авто** — если Cowork watcher активен, используем для файловых задач
- **⚠️ Подтвердить** — спрашивать каждый раз
- **❌ Никогда** — не делегировать в Claude Desktop

## Per-task Confirmation Flow

Когда настроено "Крупные задачи" и план дорогой или большой:

```
🧠 Планирую выполнить задачу в 3 шага:

[1] интернет-исследование (~15s, ~$0.010)
[2] Perplexity sonar-pro (~10s, ~$0.010)
[3] таблицы Excel/CSV (~40s, ~$0.010)

Итого: ~65с, ~$0.030

[✅ Выполнить]  [❌ Отмена]
[🎯 Проще]      [🚀 Глубже]
```

- **✅ Выполнить** — запускает план
- **❌ Отмена** — отменяет
- **🎯 Проще** — пересобирает с 1 агентом
- **🚀 Глубже** — пересобирает с расширенным анализом

## Примеры

```
# Простой запрос → 1 агент
"Что такое LangChain?" → internet_research

# Составной запрос → mesh
"Найди топ-10 AI агентов и сделай таблицу" →
  [1] perplexity_researcher
  [2] smart_table

# Файловая задача → Cowork (если активен)
/cowork создай expense report из моих PDF
→ cowork_file_agent (Claude Desktop)
```

## Команды

```
/mesh              — панель управления с кнопками
/mesh on/off       — включить/выключить Smart Router
/mesh debug        — посмотреть последний план
/mesh history      — последние 5 выполнений

/cowork status     — статус Cowork Bridge
/cowork send <задача> — отправить задачу в Claude Desktop
/cowork list       — список задач в очереди

/diag              — полная самодиагностика
```
