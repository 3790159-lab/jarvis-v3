## 1. Kling API (klingai.com / Kuaishou)

| Вопрос | Факт |
|---|---|
| AI Avatar (говорящая голова) | Есть — «Kling AI Avatar» (Standard/Pro, v2). Вход: фото + аудио(≤5MB, mp3/wav/m4a/aac) или текст. Standard до 720p, Pro/v2 до 1080p@48fps. Длительность: ранние версии ~1 мин, Avatar 2.0 заявляет до 5 мин за прогон. |
| Omni Edit / video-to-video замена персонажа | Есть — «Kling 3.0 Omni» / «Kling O1 Video-Edit» (запуск ~05.02.2026). Видео-референс + текстовое описание замены (актёр/костюм/фон), фон/движение/камера сохраняются. Вход видео до 200MB, 720–2160px, 3–10с; вывод той же длительности. |
| Цена | Consumer credits: 720p 6 cr/s (без аудио) / 9 cr/s (с аудио); 1080p 8/12 cr/s. Omni-edit через реселлера (fal.ai): ~$0.168/сек входного видео (~$0.5–1.68 за клип 3–10с). Официальная цена Avatar как отдельного API-товара **не подтверждена** — только реселлерские цены. |
| Биллинг API vs веб-Standard | **Конфликтующие данные.** Большинство источников: API — отдельный платный продукт (dev-консоль на app.klingai.com, prepaid resource packages от $9.80, «неудачные задачи не сжигают кредиты, в отличие от консьюмерских»), веб-подписка Standard — отдельный пул кредитов. Один неофициальный агрегатор утверждает обратное. **Не подтверждено напрямую** из-за geo-block официальных доков. |
| Лимиты/зрелость | Rate limits — противоречивые описания (не сверено с официальным доком). Продукт выглядит зрелым (версии V2.1–V3, O1/O3, Omni, без признаков waitlist). |

**Риск:** ключевой вопрос («отдельный ли биллинг API от веб-Standard») не подтверждён официально — требует либо VPN-доступа к klingai.com/dev-консоли, либо прямого запроса в поддержку Kling, прежде чем закладывать это в бюджет.

## 2. HeyGen API

| Вопрос | Факт |
|---|---|
| Photo Avatar | Есть, отдельный от Studio/Digital Twin. Флоу: Generate AI Photo Avatars → Photo Avatar Group → Looks → Train → Video Generation API (текст+voice_id или аудио-трек для липсинка). |
| Цена | Pay-as-you-go, без обязательной подписки, кредиты от $5 (12 мес. срок действия). По ставкам (developers.heygen.com/docs/pricing): **Avatar III Photo Avatar $0.0433/сек (~$2.6/мин)**, Avatar IV Photo Avatar $0.05/сек, Digital Twin дешевле ($0.0167–0.0667/сек). TTS отдельно $0.000667/сек. Enterprise — по запросу. |
| Лимиты | Не всё публично: разрешение по умолчанию 1080p (free — 720p), до 10 видео одновременно на pay-as-you-go. Макс. длительность генерации и точные rate-limit по тарифу — не задокументированы, нужен запрос в саппорт. |
| UA/RU в липсинке | **Подтверждено официально** — «Russian (Russia)» и «Ukrainian (Ukraine)» в списке 130+ языков Video Translation/dubbing. |
| Голос | Кастомный/клонированный голос поддержан (voice_id из List All Voices V2, включая instant-клон) — не только встроенная библиотека. |

**Интеграция:** REST + async job/poll (иногда webhook), многошаговый флоу (фото→group→look→train→generate). Средняя сложность, доки местами неполные (часть страниц редиректит/404).

## 3. Hedra (Character-3)

| Вопрос | Факт |
|---|---|
| API | Есть, self-serve (`api.hedra.com`): API-ключ после подписки → `generate-asset` (фото+аудио/текст+voice_id, `ai_model_id` для выбора модели) → poll `get-status`. |
| Цена | Общий кредитный пул веб+API. Тарифы: Basic $15/мес (1500 кр.), Creator $30/мес (5400 кр.), Professional $75/мес (14400 кр.). **Character-3: 3 кредита/сек @540p, 6 кредитов/сек @720p.** Без платной подписки API-ключ не выдаётся (free — только веб, короткие ~20с ролики). |
| Качество | Официально только маркетинговые заявления (липсинк, микро-мимика), без цифр и без сравнения с конкурентами. Сторонние обзоры: нативно ≤720p, апскейл до 2K/4K отдельным шагом — **не подтверждено официально**. |
| Доступность | Self-serve, waitlist не найден. |
| UA/RU | TTS Hedra поддерживает ~20+ языков включая русский, **украинский явно не указан**. Липсинк сам по себе аудио-агностичен (синкается на любую поданную дорожку) — можно подать украинскую дорожку из внешнего TTS. |

## Рекомендация по конвейерам

### Конвейер A: тема → сценарий → TTS → аватар → превью → пост
1. Сценарий — LLM (уже есть в стеке, из брифа `clients/<name>/brand.md`).
2. TTS + фирменный голос Веры — **ElevenLabs, Professional Voice Cloning, тариф Creator ($22/мес)**. UA/RU подтверждены официально, цена предсказуема ($0.165–0.20/1000 симв.).
3. Аватар по фото Веры (`persona_af2f54ee`) — **WaveSpeed: Kling AI Avatar (Standard) или InfiniteTalk**, т.к. это уже наш проверенный поставщик с знакомым async-паттерном (как Wan 2.2 i2v), а не отдельный биллинг-контракт с Kling или HeyGen напрямую. HeyGen — запасной вариант, если качество липсинка WaveSpeed/Kling не устроит (у HeyGen явно подтверждён UA/RU и зрелый Photo Avatar флоу, но собственный биллинг и более высокая цена/мин).
4. Превью → пост — существующий Instagram-конвейер (Этап 3).

**Ориентир стоимости одного видео (A), 30–60 сек:**
- TTS (300–500 симв. на 30-60с речи) ≈ $0.05–0.10
- Аватар-видео через WaveSpeed (Kling Avatar Standard $0.25/5с → ~$1.5–3 за 30-60с, либо InfiniteTalk $0.30/5с → аналогично) ≈ **$1.5–3.5**
- **Итого ≈ $1.6–3.6 за видео.**

### Конвейер B: референс-видео → замена персонажа → FaceValidator → превью → пост
1. Референс-видео — исходник (наш или клиентский, с целевым фоном/движением).
2. Замена персонажа — **WaveSpeed `wan-2.2/animate`** (до 120с, 720p, сохраняет фон/движение — прямое попадание в задачу) или `video-face-swap`/`akool/video-face-swap` для более простого face-only свопа. Kling Omni Edit (через WaveSpeed-реселл или напрямую) — альтернатива с более сильным text-driven редактированием, но менее предсказуемая цена.
3. FaceValidator — уже есть в стеке (`app/services/block_m2_face_swap/face_validator.py`), известная проблема — InsightFace fallback на Haar (~60% детекция, см. Day 8 backlog P3) — **до продакшена Этапа 4 стоит закрыть этот баг**, иначе конвейер B будет часто ложно отклонять валидные результаты.
4. Превью → пост — существующий Instagram-конвейер.

**Ориентир стоимости одного видео (B), клип 10-30с:**
- `wan-2.2/animate` или `video-face-swap`, по $0.05–0.30 за 5с блок ≈ **$0.5–2.0 за клип 10-30с** (без учёта возможных повторных прогонов при отклонении FaceValidator'ом).

### Общие риски/открытые вопросы
1. **Kling biling model не подтверждён** — если решим идти напрямую (не через WaveSpeed), нужен либо VPN-доступ к klingai.com dev-консоли, либо запрос в поддержку Kling, прежде чем планировать бюджет.
2. **FaceValidator баг** (InsightFace→Haar fallback) — прямая зависимость конвейера B, числится в Day 8 backlog P3, не входит в объём этой разведки.
3. **`clients/<name>/brand.md`** — конвенция брифа тематики упомянута в спеке задачи, но папки `clients/` в репозитории пока нет — нужно решить на Этапе 3c/4, где будет жить бриф клиента.
4. Ни один реальный платный API-вызов в ходе этой разведки не совершён — все цифры взяты из официальных/реселлерских прайс-страниц.
