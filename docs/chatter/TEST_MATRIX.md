## 5. Новая метрика: счётчик «ты бот?»

Реализовано в `chatter/run.py`: при каждом `is_bot_question(text)` пишется `control_event` вида `bot_question` (с `contact_id`), **независимо от honesty-режима** — метрика меряет частоту вопроса, а не факт раскрытия. Читается `store.count_events("bot_question", since_ts=...)`.

Тесты: `test_bot_question_counter_emitted_in_honest_mode`, `..._even_in_free_mode`, `..._not_emitted_for_ordinary_message`, `..._counts_per_contact_contact_id_tagged` (все ✅).

**Хвост (не блокер):** вывести счётчик в `/status` владельцу — сейчас он только в БД (queryable). Для пилотных данных достаточно; UI-строку добавим в дашборде (Фаза 5) или отдельной строкой /status по запросу.
