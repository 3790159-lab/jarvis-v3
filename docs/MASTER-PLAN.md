## 🎯 Стратегическая цель

**Ядро продукта — «Мастер-Инстаграм»**: AI-маркетолог + контентмейкер + SMM в одном флаконе.
Понимает нишу и тренды (через BU-браузер) → строит контент-план → генерирует контент
(наши движки: фото/видео/LoRA-персона/аватары) → пишет тексты → публикует по расписанию →
измеряет метрики → корректирует стратегию. Петля замкнута.

**Монетизация:** контент-сервис по подписке (€200–400/мес/клиент) для UA-рынка и украинской
диаспоры в Европе. Обкатка на собственных заведениях ДО продажи ресторана → кейсы с цифрами →
первые внешние клиенты. Лендинги — апсейл к клиентам ядра. Игры — эксперимент после дохода.

**Параллельная мечта, которая финансируется этим же планом:** Визирь (Ступень 3) —
цепочки команд, расписания, самостроительство с воротами. Первая цепочка Визиря =
первая продуктовая фича Мастер-Инстаграма.

## 🗺️ Этапы (строго по порядку)

### Этап 0 — Router money-gate 🔴 БЛОКЕР ВСЕГО
**Что:** закрыть архитектурную дыру: `_route_plain_text → route_message` вызывает платные
инструменты в обход `guard_spend` и confirm. План готов: `docs/superpowers/plans/2026-07-08-router-money-gate.md`.
**Ключевое решение:** гейт на границе исполнения инструмента, триггер `tool.paid`,
а не текст юзера → «фраза не влияет» становится структурным свойством.
**Приёмка:** «сделай фото не спрашивая» → confirm появляется; регресс зелёный;
живой тап Daniil на реальной фразе.
**Оценка:** ~неделя.

### Этап 1 — Регресс-гейт dev_task в боеготовность
**Что:** батчи + RAM-guard + свежий baseline. Чинит таймауты регресса и протечку
тестов в прод-чат. На 16 ГБ должно летать.
**Зачем:** без этого конвейер не переварит длинную очередь задач арки — а очередь будет.
**Приёмка:** полный регресс проходит без таймаута; тесты не протекают в прод-чат;
dev_task с падающим регрессом не предлагает [Мердж].
**Оценка:** 1–2 недели.

**Накопленные хвосты конвейера (взять в Этап 1, первой — single-instance B+C):**
1. `[ ]` **Single-instance guard, слои B+C** (корень двойного поллера; слой A —
   OS-лок бота — сделан 2026-07-09, коммит `3ba8b03`):
   - **B:** `bot_guardian_detached.ps1` `Stop-OldBot` надёжный — убивать по PID+дерево,
     **дождаться подтверждённой смерти**, и если хоть один jarvis-процесс жив —
     **не запускать** новый (никогда не стартовать поверх живого); `bot.pid` удалять
     только после смерти.
   - **C:** дебаунс `Test-Bot` — N подряд протухших heartbeat перед relaunch + поднять
     `HeartbeatMaxAgeSec`, чтобы транзиентный RAM/GC-столл не плодил дубль-relaunch.
2. `[ ]` **Ancestor-check влитых веток в конвейере** — при `merge-base --is-ancestor`
   ветки в прод автоматически закрывать карточку (merged), не оставлять зависшей
   (ручная уборка 8e1dc8 2026-07-09).
3. `[ ]` **Изоляция тестовых уведомлений от прод-чата** — регресс/тесты не должны слать
   в реальный чат админа (протечка petya/555; см. [[jarvis-devtask-regress-gate-techdebt]]).
4. `[ ]` **RAM-guard + батчи регресса** — полный pytest одним процессом не влезает на
   8→16 ГБ; бить на батчи + сторожить память, обновлять baseline.
5. `[ ]` **Таргет-режим регресса** — ветка `devtask-…cf31a4` (коммит `272f292`,
   awaiting_review) уже реализует обход полного регресса по диффу; верифицировать и
   влить как часть Этапа 1.

## ⚙️ Политика автономии CC (минимум подтверждений Daniil)

**CC работает БЕЗ подтверждений (полная автономия):**
- всё внутри worktree: код, тесты, рефакторинги, коммиты
- прогон тестов, регресса, линтеров
- чтение любых файлов проекта, логов, git-истории
- создание/обновление документации и планов

**🔴 Красные линии (НЕ обсуждаются, нарушение = провал задачи):**
1. **Никакого авто-режима на путях с платными API** (WaveSpeed/Replicate/Grok/Anthropic
   billable). Любой тест, который может дёрнуть реальный платный вызов — только мок,
   либо явное разрешение Daniil. Урок от 25.06.
2. **[Мердж] — только тап Daniil.** CC готовит ветку, отчёт и кнопки — не мерджит сам.
3. **Живой тест на этап обязателен.** «Зелёный зуб ≠ живое поведение» — пойман 5+ раз.
   CC готовит чеклист живого теста так, чтобы Daniil потратил ≤5 минут и 1–2 тапа.
4. **Временно отключил (гардиан/сервис/гейт) ради операции → верни и докажи что вернул.**
5. **Честный провал > лживый успех.** Не автозаполнять несделанное, не подтверждать
   чужие галлюцинации. Факт — только git и живой прогон.

**Роль Daniil на каждый этап (целевой минимум):**
кинуть `/dev_task` → дождаться отчёта → живой тест по чеклисту (≤5 мин) → тапнуть [Мердж].
